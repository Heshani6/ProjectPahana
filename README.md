# Pahana Edu Bill System

## Project Overview
The **Pahana Edu Bill System** is a web-based application designed to manage customer billing information for Pahana Edu, a leading bookshop in Colombo City. The system replaces manual record-keeping with a digital solution, providing staff and administrators with a secure and organized way to handle customer accounts, track transactions, and generate reports.

Key features include:
- User authentication for admin and staff.
- Customer account management (create, update, delete).
- Billing management and invoice generation.
- Role-based dashboards for staff and admin.
- Secure session handling and form validation.
- Automated testing of critical modules using JUnit.

---

## Technologies Used
- **Backend:** Java, JSP, Servlets
- **Frontend:** HTML, CSS, Bootstrap (for responsive UI)
- **Database:** PostgreSQL
- **Testing:** JUnit 5 (for unit testing servlets and services)
- **Version Control:** Git and GitHub
